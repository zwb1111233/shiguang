# 拾光 · 微信小程序版

「拾光」的微信小程序版本，与网页版功能对齐，**零依赖、零框架、开箱即用**——数据全部保存在手机本地，不需要服务器。

## 功能

| 模块 | 说明 |
|---|---|
| 首页 | 问候语、今日一言（可换）、连续/累计/媒体统计、记录入口、那年今天、最近的记录、历史上的今天 |
| 发布 | 心情 emoji、文字（#标签自动归类）、日期可选（可补记）、照片最多 12 张、视频 1 个（自动带封面帧） |
| 手账 | 双列瀑布流、关键词/标签搜索、按日期/那年今天筛选、下拉刷新、上滑分页 |
| 详情 | 小红书式布局：媒体轮播（图片可双指预览、视频可播放）→ 日期心情 → 正文 → 标签；支持编辑、删除、微信好友分享 |
| 编辑 | 与发布同页复用：改文字/心情/日期、增删照片视频 |
| 日历 | 月历心情标记（颜色 = 心情）、左右翻月、点日期直达当天记录 |
| 报告 | 年度篇数/天数/字数/最长连续、心情分布、每月节奏、高频标签 |
| 设置 | 深色模式（跟随系统/手动）、隐私锁（4-8 位数字，支持修改/关闭）、导出备份（微信发送 JSON 文件）、清空数据 |
| 分享 | 转发给好友的卡片带标题与封面；好友打开显示精美的分享摘要页 |

## 快速开始

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → **导入项目** → 目录选择本 `miniprogram` 文件夹 → AppID 选「测试号」即可
3. 编译运行，开始记录

> 「历史上的今天」会尝试请求维基百科接口。开发者工具里请勾选 **详情 → 本地设置 → 不校验合法域名**；正式发布需要在公众平台把 `api.wikimedia.org` 加入 request 合法域名（不配置也不影响，会用内置数据兜底）。

## 数据与隐私

- 结构化数据存在微信 Storage，照片/视频拷贝到小程序用户目录（`sg-media/`），全部留在本机
- 隐私锁使用加盐散列校验（日常防 peek 用途）
- 导出：设置 → 导出备份，通过微信文件助手把 JSON 发给自己

## 目录结构

```
miniprogram/
├── app.js / app.json / app.wxss / theme.json   # 入口、路由、设计变量、深色模式
├── assets/tab/                                  # tabBar 图标
├── utils/
│   ├── store.js     # 数据层（记录 CRUD、统计、隐私锁、导出）
│   ├── util.js      # 格式化、瀑布流两列算法、触感反馈
│   ├── quotes.js    # 今日一言
│   └── onthisday.js # 历史上的今天（Wikimedia API + 内置兜底）
└── pages/           # home / notes / detail / compose / calendar / report / settings / lock
```

## 与网页版的关系

两版是独立的两个客户端，数据各自保存在各自的设备上（网页版在本机数据库，小程序版在手机里）。网页版（仓库根目录）适合电脑前长文记录，小程序版适合随手拍随手记。
