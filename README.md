# 拾光 · 每日心情手账

> 把每一天，都好好收藏。

「拾光」是一个跑在自己设备上的个人心情手账：每天记录一点感受、几张照片、一段视频，界面遵循 Apple 设计风格——干净、留白、圆润、克制。

- **网页版**（本目录）：Node.js + Express + SQLite，数据保存在自己电脑上
- **微信小程序版**（[miniprogram/](miniprogram/)）：原生小程序，数据保存在手机里，零依赖开箱即用

## 功能一览

**首页**
- 📖 **今日一言** —— 每天自动换一句关于热爱生活的句子，可手动切换
- 🕰️ **历史上的今天** —— 自动按当天日期加载真实历史事件（维基百科数据，断网时使用内置数据）
- ✍️ **记录今天** —— 心情 emoji + 文字 + 多张照片 + 视频，正文里写 `#标签` 自动归类，`Ctrl+Enter` 快速发布
- 🎂 **那年今天** —— 首页会告诉你去年、前年的今天你写了什么
- 🖼 **最近的记录** —— 小红书式瀑布流卡片

**全部页面**
- 📔 **手账** —— 全部记录的瀑布流浏览，支持按日期 / 标签 / 关键词筛选
- 📖 **笔记详情** —— 点开任意记录，左图右文的沉浸式浏览，轮播翻页（键盘 ← → 也可）
- ✏️ **编辑记录** —— 详情页一键进入编辑：改文字、换心情、挪日期、增删照片视频
- 📅 **心情日历** —— 月历上用颜色标出每天的心情，点日期直达当天记录
- 📊 **年度报告** —— 记录篇数、写字数、心情分布、每月节奏、最长连续记录、高频标签
- 🔍 **搜索** —— 顶栏搜索浮层，按关键词 / 标签快速找回忆忆
- 🔒 **隐私锁** —— 4-8 位数字密码，打开网站需解锁；支持修改密码、一键锁定
- 🌗 **深色模式** —— 浅色 / 深色 / 跟随系统三种模式
- 🖼 **自定义壁纸** —— 亮色、暗色模式各有 4 套内置壁纸，也可以上传自己的照片
- 🎬 **视频封面** —— 上传视频时自动截取画面生成封面，列表与详情都更好认
- 🔗 **分享** —— 单条记录可开启分享链接（好友打开是精心排版的分享页），支持系统分享、复制链接、生成高清分享图片
- 📤 **数据导出** —— 一键导出全部文字记录为 JSON

## 快速开始

### 方式一：双击启动（推荐）

1. 安装 [Node.js](https://nodejs.org/)（18 以上版本）
2. 双击 `启动拾光.bat` —— 首次运行会自动安装依赖
3. 浏览器会自动打开 `http://localhost:3000`

### 方式二：命令行

```bash
npm install
npm start
```

### 微信小程序版

见 [miniprogram/README.md](miniprogram/README.md)——用微信开发者工具导入 `miniprogram/` 文件夹即可运行。

## 数据保存在哪里？

所有数据都在本地，不上传到任何服务器：

| 内容 | 位置 |
|---|---|
| 数据库（文字、心情、标签） | `data/shiguang.db` |
| 照片、视频 | `uploads/media/` |
| 上传的壁纸 | `uploads/wallpapers/` |

**备份**：直接复制 `data/` 和 `uploads/` 两个文件夹即可。
**导出**：设置 → 数据 → 导出 JSON。

> 💡 首次打开是空的？随手记几条，或者正式使用前先在设置里开启隐私锁。想清空演示数据的话，关闭网站后删除 `data/` 与 `uploads/` 文件夹再启动即可。

## 常见问题

- **端口被占用？** 服务器会自动换到 3001-3010 端口，以启动时命令行打印的地址为准。也可以用 `set PORT=8080` 后再 `npm start` 指定端口。
- **想清空所有记录重新开始？** 关闭网站后删除 `data/` 和 `uploads/` 文件夹即可。
- **换电脑迁移？** 拷贝整个 `shiguang` 文件夹（含 data 和 uploads），新电脑装好 Node.js 后启动即可。

## 目录结构

```
shiguang/
├── server.js          # Express 后端与全部 API
├── db.js              # SQLite 数据库初始化
├── public/
│   ├── index.html     # 主站
│   ├── style.css      # 全站样式（Apple 风格 + 深浅色主题）
│   ├── app.js         # 前端逻辑（路由、发布、日历、报告……）
│   ├── share.html     # 好友打开的分享页
│   ├── favicon.svg    # 网站图标
│   └── wallpapers/    # 8 套内置壁纸（亮色 4 / 暗色 4）
├── data/              # 运行时生成：SQLite 数据库
├── uploads/           # 运行时生成：照片、视频、壁纸
└── 启动拾光.bat        # Windows 一键启动
```

## 技术栈

- **后端**：Node.js + Express + better-sqlite3 + Multer
- **前端**：原生 HTML / CSS / JavaScript，零框架、零构建
- **历史数据**：Wikimedia Feed API（含本地缓存与内置兜底数据）
